* Cues

Cues is a script that turns a text file into a ~.wav~ audio file. It plays
click and vocal cue samples ("verse", "four", "three", ...) at the beats
you specify, mixing them together into a single audio file you can use
directly, or import into your DAW.

The word samples and metronome ("clave") samples live in
~~/Library/CloudStorage/Dropbox/Music/samples/cue-and-click-wavs~.

* Cue File

The text file format is simple:

- t NN :: (t/track) Sets the tempo to NN beats per minute. Default is 120
  bpm.
- N/M :: Sets the time signature. Default is 4/4.
- v N :: (v/subdivision) Sets the click subdivision. 4 is a quarter note
  (default), 8 is an eighth, etc. The default is 4 (quarter notes).
- m N :: (m/measure) Inserts N measures of clicks.
- b N :: (b/beat) Inserts N beats of clicks.
- c <name> ... :: (c/cue) Cues leading into the next measure or beat. "Name"
  can be any name or the shortcuts "1234" or "234". Each name will be played
  on a beat.
- 1234 :: A shortcut for writing the three lines "one", "two", "three", and
  "four"
- 234 :: A shortcut for writing the three lines "two", "three", and "four"
- d <clave-name> :: (d/downbeat) Sets which ~clave-*.wav~ sample plays the
  metronome downbeat (the first beat of each measure). "clave-name" is the
  part of the file name after "clave-", e.g. "high" for
  ~clave-high.wav~. The default is "high".
- k <clave-name> :: (k/click) Sets which ~clave-*.wav~ sample plays the
  metronome click (every beat other than the downbeat). The default is
  "low". The downbeat and click can be set to the same sample if you want
  every beat to sound the same.

Anywhere a ~#~ appears, it and the following text is ignored, allowing you
to add comments to the file. Blank lines are also ignored.

Any other line that's not a comment will treat its first word as a name.
Each name must be one of the built-in names below, or "rest" for a silent
beat. The matching sample will be played starting at the current beat, and
the time will be advanced to the next beat.

- <name> :: Insert the sample on the beat and move to the next beat.

The built-in names, each backed by a ~.wav~ file of the same name in the
samples directory:

- one
- two
- three
- four
- intro
- verse
- chorus
- bridge
- end
- rest (plays nothing; just advances to the next beat)

Samples can overlap. If a word sample is longer than one beat, it keeps
playing while later clicks or words start on subsequent beats, just as it
would if spoken over a click track.

Here's an example file:

#+begin_example
  # Here's a sample Cues file. This text is ignored. This sample file
  # uses the abbreviations for each of the commands ("t" for tempo,
  # "c" for cue).

  t 120    # Set tempo to 120 (the default)
  4/4      # Set the time signature (4/4 is also the default)
  v 4      # Set the click subdivision. 4 == quarter note (default),
           # 8 == eighth, etc.

  # Count-in. First bar contains four clicks. Second bar contains four
  # notes, one on each beat: "intro", "two", "three", and "four". See
  # "cue" below for a slightly shorter way to write this.
  m 1
  intro
  234

  # Intro
  m 8      # 8 bars of intro

  # A cue. Because there are four notes in this cue ("verse", "two",
  # "three", and "four"), we travel "back in time" four beats to play
  # them. On the 7th measure of the intro, the four notes will be
  # played one per beat.
  cue verse 234  # could type "c" instead of "cue"

  # Verse 1
  m 16

  # Verse 2 with cue to the chorus
  m 16
  c chorus 234

  # Chorus with cue to the next verse. Since comment lines and blank
  # lines are ignored, it doesn't matter if you put the cue line right
  # after the chorus, or right before the verse. It's personal preference.
  m 8

  # Verse with a cue before it
  c verse 234
  m 16

  # Bridge, with cue before it
  c bridge 234
  m 16

  # ... the rest of the song ...
#+end_example
